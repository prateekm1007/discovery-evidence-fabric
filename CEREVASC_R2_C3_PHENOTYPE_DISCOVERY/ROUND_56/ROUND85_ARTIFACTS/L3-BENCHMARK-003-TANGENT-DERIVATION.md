## 1. Constitutive setup (recap)

- SED: `W = (μ/2)(Ī₁ − 3) + (K/2)(J − 1)²`
- μ = 0.3846, K = 0.8333 (from E=1.0, ν=0.3)
- Deformation: uniaxial z-tension, `F = diag(λ_t, λ_t, λ_z)`, λ_z prescribed
- Lateral contraction: λ_t solved from σ_xx = 0

---

## 2. What is the "tangent" we need?

For a Newton solver, the relevant tangent is the **consistent tangent
stiffness matrix** `K_T = ∂R/∂u`, where `R` is the residual vector.

For hyperelasticity with diagonal F, the relevant scalar projection of
the tangent is the **dσ/dε** relationship — specifically, for uniaxial
z-tension, `dσ_zz/dλ_z` (the slope of the Cauchy stress-stretch curve).

If two solvers produce the same stress at a given stretch but different
slopes `dσ_zz/dλ_z`, they will:
- Agree at the solution point (if they converge)
- But take different Newton paths to get there
- And may fail differently for problems where the path matters

---

## 3. Derivation of σ_zz(λ_z)

From the analytical derivation (L3-BENCHMARK-002-ANALYTICAL-DERIVATION.md):

```
σ_zz = (λ_z² / J) · S_zz

S_zz = (2μ/3) · J^(-2/3) · [1 − λ_t²/λ_z²]  +  K(J − 1) J / λ_z²

with λ_t² = J / λ_z, so:
  λ_t²/λ_z² = J / λ_z³
  1 − λ_t²/λ_z² = 1 − J/λ_z³

J determined by the lateral-contraction equation:
  f(J; λ_z) = (μ/3) · J^(-2/3) · (J/λ_z − λ_z²)  +  K(J − 1) J  =  0
```

So `σ_zz` is implicitly a function of `λ_z` via `J(λ_z)`.

---

## 4. Compute dσ_zz/dλ_z analytically

Differentiating σ_zz(λ_z) with J(λ_z) implicit:

```
dσ_zz/dλ_z = ∂σ_zz/∂λ_z + (∂σ_zz/∂J) · (dJ/dλ_z)
```

where dJ/dλ_z is obtained by differentiating f(J; λ_z) = 0:

```
df/dλ_z = (∂f/∂λ_z) + (∂f/∂J) · (dJ/dλ_z) = 0
=> dJ/dλ_z = − (∂f/∂λ_z) / (∂f/∂J)
```

### 4.1 Partial derivatives of f(J; λ_z)

```
f(J; λ_z) = (μ/3) · J^(-2/3) · (J/λ_z − λ_z²)  +  K · (J − 1) · J
```

**∂f/∂λ_z:** only the first term depends on λ_z (the K·(J-1)·J term does not):

```
∂f/∂λ_z = (μ/3) · J^(-2/3) · ∂/∂λ_z [J/λ_z − λ_z²]
        = (μ/3) · J^(-2/3) · [−J/λ_z² − 2λ_z]
```

**∂f/∂J:**

```
∂f/∂J = (μ/3) · ∂/∂J [J^(-2/3) · (J/λ_z − λ_z²)]  +  K · ∂/∂J [(J − 1) J]
      = (μ/3) · [(-2/3) J^(-5/3) · (J/λ_z − λ_z²)  +  J^(-2/3) · (1/λ_z)]  +  K · (2J − 1)
```

So:
```
dJ/dλ_z = − [(μ/3) · J^(-2/3) · (−J/λ_z² − 2λ_z)] / [(μ/3) · ((-2/3) J^(-5/3) (J/λ_z − λ_z²) + J^(-2/3)/λ_z) + K(2J − 1)]
```

### 4.2 Partial derivatives of σ_zz

```
σ_zz = (λ_z² / J) · [(2μ/3) · J^(-2/3) · (1 − J/λ_z³)  +  K(J − 1) J / λ_z²]
```

Let `S_zz = (2μ/3) · J^(-2/3) · (1 − J/λ_z³)  +  K(J − 1) J / λ_z²`, so
`σ_zz = (λ_z² / J) · S_zz`.

**∂σ_zz/∂λ_z** (holding J fixed):

```
∂/∂λ_z [λ_z² · S_zz / J] = (2λ_z / J) · S_zz  +  (λ_z²/J) · ∂S_zz/∂λ_z

∂S_zz/∂λ_z (holding J fixed):
  = (2μ/3) · J^(-2/3) · ∂/∂λ_z [1 − J/λ_z³]  +  K(J-1) J · ∂/∂λ_z [1/λ_z²]
  = (2μ/3) · J^(-2/3) · [3J/λ_z⁴]  +  K(J-1) J · [−2/λ_z³]
  = (2μ/3) · J^(-2/3) · 3J/λ_z⁴  −  2K(J-1) J / λ_z³
```

**∂σ_zz/∂J** (holding λ_z fixed):

```
∂/∂J [λ_z² · S_zz / J] = λ_z² · [ (∂S_zz/∂J) / J  −  S_zz / J² ]

∂S_zz/∂J (holding λ_z fixed):
  = (2μ/3) · ∂/∂J [J^(-2/3) (1 − J/λ_z³)]  +  K · ∂/∂J [(J-1) J / λ_z²]
  = (2μ/3) · [(-2/3) J^(-5/3) (1 − J/λ_z³)  +  J^(-2/3) · (-1/λ_z³)]  +  K(2J − 1)/λ_z²
```

### 4.3 Final tangent

```
dσ_zz/dλ_z = ∂σ_zz/∂λ_z + (∂σ_zz/∂J) · dJ/dλ_z
```

This is algebraically complex; we compute it numerically in the
verification script using `scipy.misc.derivative` for cross-check.

modulus E = 1.0. This is the **small-strain consistency check**: any
correct implementation of compressible neo-Hookean must reduce to linear
elasticity at infinitesimal strain.

## 6. Tangent equivalence check (8th CE-GATE check)

The new check #8 evaluates:

```
tangent_equivalence = (|dσ_zz/dλ_z_analytical − dσ_zz/dλ_z_solver_A| < tolerance)
                      at all 5 deformation states
                    AND (|dσ_zz/dλ_z_analytical − dσ_zz/dλ_z_solver_B| < tolerance)
                      at all 5 deformation states
```

**Tolerance:** 1% relative (tighter than the 5% stress tolerance, because
tangent should match to machine precision for an exact constitutive
replication).

**Failure modes this catches:**
- Solver uses an approximate tangent (e.g., numerical differentiation
  with finite differences too large)
- Solver uses a different tangent formulation (e.g., material vs
  consistent tangent)
- Solver has a bug in the tangent implementation that produces correct
  stress but wrong slope
- Solver uses a quasi-Newton approximation (e.g., BFGS) that has not
  yet converged to the true tangent

For FEBio's BFGS quasi-Newton: the solver does NOT compute the true
tangent analytically; it builds a secant approximation. So the
`tangent_equivalence` check is meaningful ONLY for the constitutive
tangent (computed analytically or via automatic differentiation), NOT
for the solver's internal BFGS approximation. The check should be
applied to the **material tangent** (dσ/dε computed from the
constitutive law), not the **solver tangent** (the matrix actually used
in Newton iterations).

This distinction is documented in the gate's audit instructions.

## 7. Independence verification

This derivation uses:
- The frozen constitutive SED (field_2 of L3-BENCHMARK-002/003-FREEZE.json)
- The frozen BCs (field_4)
- Standard continuum mechanics (Bonet & Wood 2008, §5.4 and §6.4)
- Differential calculus (chain rule, implicit differentiation)

This derivation does NOT use:
- FEBio output (FEBio binary was wiped; no output exists)
- SfePy output
- Any prior L3 attempt's numerical tangent

The numerical evaluation of the analytical tangent (in the companion
script) uses `scipy.optimize.brentq` to solve for J(λ_z) and
`scipy.misc.derivative` for cross-checking dσ_zz/dλ_z. These are
independent computational methods.
