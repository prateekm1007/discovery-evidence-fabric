# Enablement Analysis (35 USC 112) — INV_EXP_013

**Status:** MODERATE

**Rationale:** The claim lacks sufficient detail about how the gel-resistant electrode material works, how it interacts with the signal processing module, and how the algorithms are adjusted based on gel degradation level. A person having ordinary skill in the art (PHOSITA) would need to conduct extensive experimentation to determine the appropriate material composition, detection method for gel degradation, and algorithm adjustments. The specification does not provide adequate guidance for these critical aspects.

**Can survive:** False

**Rule:** A PHOSITA must be able to make and use the invention without undue experimentation.
