# Enablement Analysis (35 USC 112) — INV_EXP_001

**Status:** MODERATE

**Rationale:** The claim lacks sufficient detail about how the mechanical shutter interacts with the photodetector to control light intensity measurement. A PHOSITA would need to experiment to determine the optimal shutter speed, synchronization between the shutter and photodetector, and calibration algorithms. The claim doesn't specify materials, dimensions, or control mechanisms for the shutter, which would require experimentation to implement.

**Can survive:** True

**Rule:** A PHOSITA must be able to make and use the invention without undue experimentation.
