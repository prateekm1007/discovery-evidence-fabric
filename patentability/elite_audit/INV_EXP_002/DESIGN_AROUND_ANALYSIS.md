# Design-Around Analysis — INV_EXP_002

**Attack strength:** MODERATE

**Easiest competitor workaround:** A competitor could design around this claim by creating a blood pressure monitoring system that eliminates the need for a dedicated processor by using cloud-based processing. The sensor could send raw data directly to a smartphone or cloud service where processing occurs, and results are displayed on the user's existing device (smartphone, tablet, or computer). This approach would avoid the claimed 'processor for processing blood pressure data' element while still achieving the economic value of enabling more frequent, accurate blood pressure monitoring outside clinical settings. The value creation types (COST_REDUCTION, IMPROVED_OUTCOMES, CONVENIENCE) would still be met, though with a different implementation architecture.

**Does competitor still obtain value?** True

**Claim refinement needed:** The claim could survive by emphasizing the integration and specific processing functions performed by the dedicated processor that cloud-based solutions cannot replicate, or by claiming specific processing algorithms that provide unique advantages.

**Rule:** For every strong claim, generate the easiest competitor workaround. If the competitor still obtains the value, DESIGN_AROUND_RISK = HIGH. Refine claim if possible.
