# Enablement Analysis (35 USC 112) — INV_EXP_020

**Status:** NONE

**Rationale:** The claim provides sufficient detail about the curved interface design and its function to enable a person of ordinary skill in the art to make and use the invention. The specific parameters of the curvature (radius, angle, etc.) would need to be specified in the specification, but the general concept is adequately described.

**Can survive:** True

**Rule:** A PHOSITA must be able to make and use the invention without undue experimentation.
