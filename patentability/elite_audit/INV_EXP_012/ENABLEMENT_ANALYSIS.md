# Enablement Analysis (35 USC 112) — INV_EXP_012

**Status:** MODERATE

**Rationale:** The claim lacks sufficient detail about the specific materials, thicknesses, manufacturing processes, and testing methods required to make and use the invention. A person of ordinary skill in the art would face undue experimentation in determining the appropriate polymer composition for the base coating, the elastomeric material for the topcoat, the optimal thickness of each layer, the integration method, and how to ensure the stress transfer mechanism functions as claimed during drug elution.

**Can survive:** True

**Rule:** A PHOSITA must be able to make and use the invention without undue experimentation.
