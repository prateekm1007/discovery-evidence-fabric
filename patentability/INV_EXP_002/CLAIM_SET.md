# Claim Set — INV_EXP_002

**Independent Claim:**
A blood pressure monitor comprising: A) a sensor for detecting blood pressure; B) a display for displaying blood pressure readings; and C) a processor for processing blood pressure data.

**Dependent Claims:**
- A blood pressure monitor according to claim 1, wherein the sensor is a non-invasive sensor.
- A blood pressure monitor according to claim 1, wherein the display is a touch screen display.
- A blood pressure monitor according to claim 1, wherein the processor is a microcontroller processor.

**Claim Elements:**
- A: detecting blood pressure
- B: displaying blood pressure readings
- C: processing blood pressure data
