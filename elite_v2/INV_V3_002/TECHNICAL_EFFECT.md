# Technical Effect — INV_V3_002

**Classification**: DOCUMENTED

## Problem
Calibration drift in blood pressure monitors caused by changes in the physical relationship between the reference pressure sensor and the blood pressure cuff

## Distinguishing Feature
Adjustable cavity design that allows positioning the reference pressure sensor at varying distances from the blood pressure cuff

## Mechanism
Physically adjusting the position of the reference pressure sensor relative to the cuff to maintain proper calibration

## Technical Effect
Compensation for calibration drift by dynamically adjusting the sensor-cuff relationship

## Effect Properties
- Unexpected: False
- Synergistic: False
- Non-linear: False
- Counterintuitive: False
