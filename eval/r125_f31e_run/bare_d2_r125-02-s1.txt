**Mitigation Proposal: Load-Limited Speed Scheduling via Ammeter Hysteresis**

**Mechanism**
Implement a closed-loop speed control logic that dynamically reduces line speed when the finish block motor current exceeds a specific threshold. The core mechanism relies on the inverse relationship between wire speed and drawing force (current): as the wire passes through the die, increased friction or resistance (indicated by climbing current) requires higher tension. By lowering the speed, the kinetic energy input is reduced, and the operator can verify if the current stabilizes, preventing the sudden snap failure associated with high-tension breakages. This creates a "soft-stop" or "slow-down" mitigation that uses the existing current measurement to infer mechanical strain before it reaches the breaking point.

**Implementation**
1.  **Parameterize Thresholds:** Configure the PLC or controller with two current thresholds using the existing per-block motor ammeters:
    *   $I_{warn}$: 90% of the observed maximum current prior to failures.
    *   $I_{trip}$: 100% of the observed maximum current.
2.  **Speed Ramp Logic:** Program the line-speed encoder (used for feedback) to command a speed reduction:
    *   If Finish Block Ammeter reading $> I_{warn}$ for a duration $> t_{hold}$ (e.g., 2 seconds), reduce target line speed by 10%.
    *   If Finish Block Ammeter reading $> I_{trip}$, reduce target line speed by 25% immediately.
    *   If Finish Block Ammeter reading $< 0.8 \times I_{warn}$ for a duration $> t_{rec}$ (e.g., 10 seconds), gradually increase speed back to nominal setpoint by 5% increments.
3.  **Interlock with Break Counter:** If the break counter registers a break, the system automatically initiates a restart sequence that starts at 50% of nominal speed. The speed then follows the hysteresis ramp-up logic above, ensuring the machine does not resume at full speed immediately after a failure, thereby preventing immediate re-breakage due to residual debris or alignment issues not yet cleared.

**Measures Relied Upon**
*   **Per-block Motor Ammeters:** Provides the real-time load signal. The climbing current in the finish block is the primary indicator of increased friction or die fouling, serving as the trigger for speed reduction.
*   **Line-speed Encoder:** Provides the actual speed feedback necessary to verify that the commanded speed reduction is being executed by the drive system and to calculate the time-average current if necessary for trend analysis.
*   **Break Counter:** Confirms the failure event and forces a conservative restart speed, ensuring that the mitigation loop (slow down on high current, restart slow after break) is robust and does not mask persistent faults by allowing high-speed operation immediately.
