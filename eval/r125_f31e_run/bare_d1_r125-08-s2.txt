**Mitigation Proposal: Closed-Loop Cycle Time Optimization via Oxygen Analyzer Feedback**

**Mechanism:**
Implement a real-time closed-loop control algorithm that dynamically adjusts the adsorption (high-pressure) phase duration of the PSA cycle based on the end-of-cycle product oxygen concentration. Instead of using a fixed, time-based timer (which is currently shortening and causing early breakthrough), the controller uses the product oxygen analyzer signal as the primary feedback variable. The cycle is allowed to run until the oxygen concentration reaches a specific target threshold (just below the purity spec limit) with a safety margin, or a maximum time limit is reached, whichever comes first. This directly addresses the "slipping purity" by ensuring the carbon bed is sufficiently loaded before switching, while preventing excessive cycle times that would lower throughput.

**Implementation:**
1.  **Signal Conditioning & Logic:** Configure the existing cycle-time counter and logic controller to accept the product oxygen analyzer as a feedback input.
2.  **Threshold Setting:** Set a "Breakthrough Threshold" for the oxygen analyzer at a value slightly conservative to the specification limit (e.g., if spec is <2% O2, set trigger at 1.5% O2).
3.  **Cycle Control Logic:**
    *   **Start:** Begin adsorption phase when valves switch.
    *   **Monitor:** Continuously read the oxygen analyzer.
    *   **Stop Condition:** End the adsorption phase when the oxygen analyzer reads the "Breakthrough Threshold" OR when a maximum safety time (derived from historical data) is reached.
    *   **Correction:** If the oxygen analyzer triggers early (indicating faster breakthrough due to aged adsorbent or flow issues), the system naturally extends the adsorption time to ensure full loading. If it does not trigger by the maximum time, the cycle is cut short to save energy and increase production rate.
4.  **Feed-Air Pressure Compensation:** Use the existing feed-air pressure transmitter to normalize the oxygen breakthrough threshold. If feed pressure drops, the air velocity in the bed decreases, slowing breakthrough. The controller can slightly relax the oxygen threshold or extend the maximum time to account for this, ensuring consistent purity despite pressure fluctuations.

**Measures it Relies On:**
*   **Product Oxygen Analyzer:** Provides the direct, real-time indicator of purity and breakthrough timing. This is the core sensor enabling the closed-loop.
*   **Feed-Air Pressure Transmitter:** Used for feedforward correction. Variations in pressure affect gas residence time in the adsorbent bed; using this signal allows the controller to adjust the cycle time or threshold to maintain purity under varying pressure conditions.
*   **Cycle-Time Counter:** Acts as the execution mechanism. It is no longer a simple fixed timer but a variable counter that is terminated by the logic above. It also provides the necessary timekeeping for the adsorption and desorption phases.

**Expected Outcome:**
*   **Purity Stabilization:** By dynamically extending the adsorption time until breakthrough is detected (with margin), the product purity is maintained at spec even as the adsorbent degrades or conditions vary.
*   **Reduced Feed-Air Consumption:** By not running the cycles longer than necessary (when the bed is healthy or pressure is high), the system avoids over-pumping. The pressure transmitter ensures that when pressure is low, the cycle isn't excessively shortened, balancing consumption and purity.
*   **Elimination of Shortening Cycles:** The "shortening" was likely a manual or fixed-timer response to perceived efficiency loss. This automated feedback ensures the cycle length is only as long as it needs to be for purity, but not shorter.
