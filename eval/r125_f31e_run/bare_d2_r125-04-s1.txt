**Mitigation Proposal: Closed-Loop Discharge Set-Point Adjustment via Specific Power Optimization**

**Mechanism:**
The observed coarsening of product and increased specific power (kW/tonne) indicates that the crusher is operating with an overly large Closed Side Setting (CSS) or under a degraded liner condition, allowing coarse material to bypass crushing or remain in the chamber. By using the **existing discharge-belt scale** to measure total throughput and the **existing motor power meter** to measure total power draw, we can calculate the **specific power consumption** in real-time. This metric serves as a proxy for the crushing intensity and CSS. Since specific power increases as CSS tightens (for a given feed) and decreases as it opens (allowing coarser discharge), we can establish a baseline specific power value corresponding to the target product size distribution. The mitigation involves manually adjusting the CSS to maintain the specific power at this baseline level, thereby compensating for liner wear and ensuring consistent discharge fineness without needing a particle size sensor.

**Implementation:**
1.  **Baseline Establishment:** After the next liner change, record the motor power and total throughput (from the discharge belt scale) under normal operating conditions. Calculate the baseline Specific Power ($P_{sp} = \text{Power}/\text{Throughput}$) that yields the desired product size.
2.  **Real-Time Monitoring:** Continuously calculate Specific Power using the live data from the motor power meter and the discharge-belt scale.
3.  **Adjustment Protocol:** 
    *   If Specific Power **drops** below the baseline, it indicates the CSS has effectively opened (due to liner wear), allowing coarse material to pass. The operator must **tighten the CSS**.
    *   If Specific Power **rises** above the baseline, it indicates excessive crushing intensity or a CSS that is too tight, wasting energy. The operator may **relax the CSS** slightly, but caution is needed as the primary issue is coarsening; thus, the focus remains on preventing the drop.
4.  **Feedback Loop:** Use the feed-rate scale to monitor incoming load. If feed rate changes, normalize the specific power calculation or adjust the target threshold accordingly to avoid false alarms. The CSS is adjusted manually by the operator based on the Specific Power trend, acting as a control system using only existing sensors.

**Measures it Relies On:**
*   **Motor Power Meter:** Provides real-time electrical load (kW), which correlates with crushing work and CSS.
*   **Discharge-Belt Scale:** Provides total mass flow rate (tonnes/hour), enabling the calculation of specific power.
*   **Feed-Rate Scale:** Used for context normalization, ensuring that power fluctuations due to feed density or rate are distinguished from CSS changes.
*   **Operator Judgment:** Uses the specific power value as an indicator to guide CSS adjustments, effectively replacing the need for a new particle size analyzer.
