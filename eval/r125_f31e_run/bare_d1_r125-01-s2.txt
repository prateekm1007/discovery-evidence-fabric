**Mitigation Proposal**

**Mechanism:**
The failure mode (increased part weight and increased screw recovery time at constant setpoints) indicates that the material in the barrel has become less dense or more viscous, likely due to thermal degradation, moisture absorption, or material lot changes that have not been accounted for. The machine's standard "shot-to-shot" feedback loop is insufficient because the drift is slow (weeks) and cumulative. The mitigation is to implement a **Closed-Loop Thermal and Dosing Stability Control** using only existing sensors.

1.  **Thermal Baseline Validation & Adjustment:** Use the **barrel zone thermocouples** to audit the actual thermal profile against the ideal process window. If the material is degrading, its melt viscosity changes. Adjust the **barrel zone setpoints** (specifically the metering and transfer zones) to maintain the target melt temperature despite the changing material state. This directly addresses the root cause of the viscosity/density change causing the weight and recovery time drift.
2.  **Dosing Compensation via Screw Recovery Analysis:** Use the **cycle-time logger** to isolate the screw recovery (metering) time. Implement a feedback rule: if the screw recovery time exceeds the historical baseline by a defined threshold (e.g., >5% deviation over 50 cycles), automatically increase the screw recovery speed or adjust the back-pressure setting (if controllable via existing PLC logic without new sensors) to reduce residence time and minimize thermal degradation. This prevents further drift.
3.  **Weight-Based Process Window Tightening:** Use the **check-weigher** data to create a real-time SPC (Statistical Process Control) chart for part weight. When the mean weight drifts above the target, trigger an immediate corrective action: reduce the injection volume (shot size) by a calculated delta to bring the mean weight back to target. This is a direct, sensor-driven compensation for the drift.

**Implementation:**

1.  **Data Aggregation:** Configure the existing cycle-time logger to export timestamped data for screw recovery time, cycle time, and check-weigher results.
2.  **Baseline Establishment:** Calculate the 90-day moving average for screw recovery time and part weight from the existing log. Define control limits at ±2% of this baseline.
3.  **Algorithm Development (PLC/Machine HMI Logic):**
    *   **Step 1 (Thermal Check):** At the start of every shift, verify that the barrel thermocouple readings are stable within ±1°C of the setpoint. If the material has changed (inferred from unexpected viscosity shifts), manually adjust the barrel setpoints to restore the target melt state. *Constraint Note:* This relies on operator intervention using existing thermocouple feedback, not new sensors.
    *   **Step 2 (Feedback Correction):** Implement a PID-like correction loop in the machine controller:
        *   Input: Check-weigher mean (last 100 parts).
        *   Target: Spec target weight.
        *   Action: If mean > target, reduce the injection shot volume by `(Mean - Target) / (Sensitivity Coefficient)`. The Sensitivity Coefficient is derived from historical data (e.g., 0.1g weight change per 0.01cm³ shot change).
        *   Input: Screw recovery time (from cycle logger).
        *   Action: If recovery time > baseline + 5%, increase screw back-pressure or recovery speed to reduce residence time and limit degradation.
4.  **Validation:** Run a 500-cycle test. Confirm that part weight returns to target within 100 cycles and screw recovery time stabilizes at baseline. Monitor scrap rate at the quality gate for 24 hours.

**Measures it Relies On:**

1.  **Barrel Zone Thermocouples:** Used to verify the melt temperature stability and guide manual setpoint adjustments to counteract material state changes (degradation/moisture).
2.  **Cycle-Time Logger:** Provides the critical process variable "screw recovery time," which is a proxy for material viscosity and residence time. Its increase is the leading indicator of the problem. Used to trigger secondary corrections (back-pressure/speed) and validate process stability.
3.  **Check-Weigher:** Provides the direct quality outcome measurement (part weight). Used as the primary feedback signal for the shot volume correction loop to directly eliminate weight drift.

**Why this works under the constraint:**
*   No new sensors are added. It uses only the three specified existing data streams.
*   It addresses the *root cause* (material state change leading to viscosity/density shift) by adjusting thermal setpoints (via thermocouples) and *symptom* (weight drift) by adjusting shot size (via check-weigher).
*   It prevents *future* drift by monitoring and correcting screw recovery time (via cycle logger), thereby managing residence time and thermal load.
