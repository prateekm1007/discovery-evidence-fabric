**Mitigation Proposal: Adaptive Duty-Cycle Regulation via Amperage-Based Thermal Protection**

**Mechanism:**
The pressure drop at the end of the stroke during long duty cycles is caused by excessive oil temperature, which lowers the oil's viscosity and increases compressibility, leading to internal leakage and reduced pump efficiency. The motor ammeter correlates directly with the hydraulic load and pump effort; however, as the system overheats, the pump requires more current to maintain pressure due to inefficiencies, or conversely, the current may drop if the system is being throttled, but a sustained high average current combined with time indicates a thermal accumulation state. By correlating the integrated electrical load (Ampere-hours) and the actual reservoir/manifold temperature readings against time, we can dynamically adjust the "long duty cycle" parameters. The mitigation involves implementing a logic gate that limits the continuous run time based on the deviation of the fluid temperature from a nominal baseline, using the existing hour-run counter to track cumulative thermal exposure rather than just time.

**Implementation:**
1.  **Establish Baseline:** Record the steady-state reservoir and manifold temperatures ($T_{ref}$) during a standard, cool-start cycle at a known load. Simultaneously, record the typical motor current ($I_{load}$) during the actuating phase of that cycle.
2.  **Logic Definition:** Program the existing control interface (or external relay logic, if the controller allows simple setpoint changes) to monitor the **Manifold Thermometer** reading. Set a **Threshold Temperature** ($T_{max}$) slightly below the manufacturer's maximum operating limit (e.g., 65°C if max is 70°C).
3.  **Dynamic Cycle Limiting:** Use the **Hour-Run Counter** not just as a totalizer, but as a duty-cycle timer. Implement a "Thermal Budget" algorithm:
    *   If $T_{manifold} < 0.8 \times T_{max}$: Allow full duty cycle.
    *   If $0.8 \times T_{max} \le T_{manifold} < T_{max}$: Reduce the allowed continuous run time (using the hour-run counter to trigger a mandatory cooldown pause) proportionally to the temperature deviation.
    *   If $T_{manifold} \ge T_{max}$: Trigger an immediate automatic stop of the pump and engage a cooling-only mode (if the system has a separate cooler loop) or a mandatory pause until $T_{manifold} < 0.7 \times T_{max}$.
4.  **Pressure Compensation Check (Optional but recommended):** While the problem states no new sensors, use the **Pump Motor Ammeter**. If the current spikes unusually for a given stroke position (which can be inferred from cycle count or time-of-stroke if the controller logs this), it indicates increased internal leak-off due to heat. The system can flag "Low Efficiency Mode" when $I_{measured} > I_{load\_expected} + \delta$, prompting the operator to shorten the duty cycle further.

**Measures it Relies On:**
1.  **Reservoir and Manifold Thermometers:** Used to directly measure the current thermal state of the hydraulic fluid. The manifold temperature is the critical indicator of the fluid's condition at the pump/valve entry, which directly impacts pressure stability.
2.  **Pump Motor Ammeter:** Used to validate the load condition. While not the primary trigger for temperature, it serves as a diagnostic cross-check. If the system is hot and the current is abnormally high, it confirms that the pressure drop is due to thermal inefficiency (leakage) rather than a mechanical failure or low oil level. It also allows for the "Thermal Budget" adjustment: high current at high temperature is the most dangerous condition, requiring the shortest duty cycle.
3.  **Hour-Run Counter:** Used to enforce the duty cycle limitations. By tying the allowed run time to the temperature state, the counter acts as the actuator for the mitigation. It ensures that the system does not operate continuously when hot, allowing the oil to dissipate heat during the mandated pauses, thereby preventing the end-of-stroke pressure drop caused by thermal runaway.

This approach uses only the specified existing sensors to create a closed-loop thermal management system that prevents the fluid from reaching temperatures where viscosity loss causes pressure failure, without adding any new instrumentation.
