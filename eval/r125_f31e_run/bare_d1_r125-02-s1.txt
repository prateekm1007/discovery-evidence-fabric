**Mitigation Proposal: Closed-Loop Tension Modulation via Motor Current Feedback**

**Mechanism:**
The increase in motor current while maintaining correct outer diameter (gauge to print) indicates a hidden increase in internal stresses or friction drag within the draw block, likely due to slight wear, misalignment, or temperature drift. This hidden load is causing premature wire failure (breaks). By using the existing per-block motor ammeters as real-time proxy sensors for axial tension/load, we can actively modulate the line speed to keep the motor current within a safe baseline range, thereby preventing the accumulation of critical stress that leads to breaks.

**Implementation:**
1.  **Baseline Establishment:** Record the nominal motor current ($I_{nom}$) for the finish block (and potentially upstream blocks) during a period of stable production with zero breaks. Define a safe upper limit threshold $I_{max} = I_{nom} \times 1.1$ (10% margin) and a target operating band.
2.  **Control Logic:** Implement a feedback loop using the existing PLC and line-speed encoder. The control algorithm continuously samples the motor ammeter reading ($I_{act}$) of the finish block.
3.  **Speed Adjustment:** 
    *   If $I_{act} > I_{max}$, the controller reduces the line speed setpoint by a small increment (e.g., 1-2%) per sampling cycle. Slowing the wire reduces the instantaneous tensile load and allows the thermal/mechanical load to dissipate or stabilize.
    *   If $I_{act}$ remains above $I_{max}$ for a sustained period (indicating a hard mechanical fault, not just a transient load spike), the system triggers an automatic line stoppage using the break counter logic to prevent a hard wire snap.
    *   If $I_{act} < I_{nom} \times 0.9$, the system can cautiously increment the speed back towards the target, as the load is within acceptable limits.
4.  **Break Counter Integration:** Use the existing break counter as a primary reset condition. If a break is detected, the system halts, and after manual restart, it initiates the process at a conservative low speed, allowing the current to stabilize before gradually ramping up.

**Measures Relied On:**
*   **Per-block Motor Ammeters:** Used as the primary feedback signal for axial load/tension. The assumption is that for a given wire material and cross-section, increased drawing force directly correlates with increased motor current.
*   **Line-Speed Encoder:** Used to adjust the actual wire feed rate, which is the actuator variable for the tension control loop.
*   **Break Counter:** Used as a failsafe state indicator. A non-zero count triggers a mandatory reset of the control logic to a safe, low-speed state, ensuring the mitigation strategy is re-evaluated after any failure event.

**Why this works under the constraints:**
*   No new sensors are added; only existing ammeters, encoders, and counters are used.
*   It directly addresses the symptom of "climbing motor current" by preventing it from reaching the failure threshold through proactive speed reduction.
*   It addresses "multiplied breaks" by removing the peak load conditions that cause the breaks, without requiring new diagnostics of the block internals.
