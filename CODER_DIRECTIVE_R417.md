## Phase 1 — Define invention quality

Create a machine-readable quality contract:

```
INVENTION_QUALITY
├── problem_fit
├── evidence_support
├── causal_coherence
├── capability_transfer
├── architecture_delta
├── implementation_feasibility
├── novelty_signal
├── attack_status
├── simulation_status
└── experimentability
```

Do not collapse it into one meaningless score. Each dimension carries
its own measured basis (derived from the run's own artifacts — never
asserted by prose). Every dimension must state its evidence source and
its uncertainty; a dimension with no evidentiary basis is UNKNOWN, not
a midpoint.

## Phase 2 — Make frontier transfer explicit

Every evolved architecture must say:

```
TARGET_BOTTLENECK
FRONTIER_CAPABILITY
FRONTIER_SOURCE
WHY_FRONTIER
TRANSFER_MECHANISM
TARGET_REGIME
NEW_INTERACTION
CAUSAL_EFFECT
```

The evidence for the frontier capability must be INDEPENDENT from the
invention's own generated prose (a retrieved record, a measured source
— not the generator describing its own transfer).

## Phase 3 — Add "WHY THIS IS DIFFERENT"

For every generation:

- GEN 1: What existed before? What did it change?
- GEN 2: What was inherited? What changed? Why did that change attack
  the previous failure?

This becomes both a machine artifact and a website panel.

## Phase 4 — Make 3D generation follow lineage

For geometric inventions: GEN 1 → model-001.glb, GEN 2 →
model-002.glb, GEN 3 → model-003.glb. The UI shows a GEN 1 | GEN 2 |
GEN 3 navigator and dynamically shows "What changed?". The geometry
must be generated from the engineering representation, not
hand-authored separately for the UI.

## Phase 5 — Build WHY IT WORKS

Clicking a 3D component exposes: component → function → causal
mechanism → supporting evidence → simulation → uncertainty.

## Phase 6 — Add physical status honesty

Every invention distinguishes DESIGNED / EVIDENCE-SUPPORTED /
SIMULATED / EXPERIMENTALLY VERIFIED — from the canonical invention
state, never from frontend inference.

## Phase 7 — Implement /rebuild

A user changes a parameter (e.g. diameter 3.0 → 3.4 mm); then:
constraint check → CAD rebuild → measurements → physics if applicable
→ delta → new GLB. No mesh stretching masquerading as engineering.

## Phase 8 — Make the package downloadable from the same state

One canonical invention state generates: 3D, website, PDF, STEP, STL,
ZIP, experiment package. No separate hand-maintained versions.

## Phase 9 — Prove the end-to-end product on three distinct problems

Medical, energy, industrial/mechanical (NOT three similar problems).
For each show: problem → invention 1 → challenge → evolution →
invention 2+ → final current invention → 3D → evidence → decisive
experiment → package. The purpose: establish that the architecture
generalizes beyond the solar-panel demonstration.
