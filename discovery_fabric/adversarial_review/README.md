# Adversarial Review

Every discovery candidate is attacked:

* Is the mechanism actually transferable?
* Is the analogy superficial?
* Is the effect already known?
* Is there hidden prior art?
* Is there a physical constraint preventing transfer?
* Is the proposed effect merely correlation?
* Is there an obvious alternative explanation?
* Can the hypothesis be falsified?
* What experiment would kill it?
