# Mechanism Extraction

Do NOT merely extract keywords.

Extract structured mechanisms:

```
INPUT → PROCESS → INTERMEDIATE STATE → OUTPUT
+ CONSTRAINT
+ OPERATING CONDITIONS
+ FAILURE MODE
+ MEASURED EFFECT
+ EVIDENCE SOURCE
```

Example:
surface modification
↓ changes interfacial energy
↓ changes adhesion
↓ improves composite performance

The system must be able to compare mechanisms across domains.
