# Source Connectors

Isolated adapters for external scientific and patent knowledge infrastructures.

**Principle:** Connectors retrieve and map. They never become the authoritative corpus themselves.

## Science
- [x] OpenAlex (live, first 10k EvidenceItems delivered)
- [ ] Semantic Scholar / S2 datasets
- [ ] arXiv
- [ ] PubMed / Europe PMC
- [ ] Crossref

## Patents
- [ ] USPTO (PatentsView / Open Data Portal)
- [ ] EPO / Espacenet / OPS (where permitted)
- [ ] WIPO
- [ ] CN sources
- [ ] India patent sources
- [ ] Google Patents / BigQuery (where legitimately accessible)

Secondary sources may enrich evidence but MUST NEVER silently replace authoritative primary evidence.
